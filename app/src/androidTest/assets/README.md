`aurea-open-youtube.pcm`: audio sintético de prueba «Aurea, abre YouTube»,
generado con eSpeak NG (es, 145 palabras/minuto) y convertido con FFmpeg.
PCM signed 16-bit little endian, mono, 16000 Hz. No contiene una voz personal.
Se empaqueta solo en el APK de pruebas, no en la aplicación distribuida.
