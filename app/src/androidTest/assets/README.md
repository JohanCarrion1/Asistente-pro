`xylon-open-youtube.pcm`: audio sintético de prueba «Xylon, abre YouTube»,
generado con eSpeak NG (es, 145 palabras/minuto, pronunciación fonética «Sáilon»)
y convertido con FFmpeg. El reconocedor español devuelve «saigón», una variante
fonética que se normaliza exclusivamente al principio como palabra de activación.
PCM signed 16-bit little endian, mono, 16000 Hz. No contiene una voz personal.
Se empaqueta solo en el APK de pruebas, no en la aplicación distribuida.
